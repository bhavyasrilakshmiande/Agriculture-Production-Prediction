Agriculture Crop Production Prediction

Company

Unified Convergence Technologies (UCT)

Project Overview

This project predicts future agricultural crop production using historical crop production data and Machine Learning techniques.

Objective

To analyze agricultural production trends and predict future production values using Linear Regression.

Tools Used

- Python
- Pandas
- Scikit-learn
- Google Colab

Dataset

The dataset contains production values of various crops across multiple years.

Machine Learning Model

Linear Regression

Result

The model predicted the crop production value for the year 2012 as approximately 120.07.

Learning Outcomes

- Data preprocessing
- Data analysis
- Machine Learning model training
- Prediction using Linear Regression
- GitHub project management
